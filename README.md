# Palloncini dell'Alfabeto

An interactive browser game designed to help children practice letter recognition and spelling through a playful experience.

## Overview

Palloncini dell'Alfabeto is an educational game in which players pop floating balloons containing letters to complete words in the correct order. The project combines simple gameplay mechanics, animated visual elements, and immediate feedback to make learning more engaging.

## Features

- **Interactive gameplay:** Click the balloons containing the next letters of the target word, in the correct order.
- **Dynamic animations:** Colorful balloons float across the screen, with visual effects when the correct letters are selected.
- **Word groups:** Choose between different sets of words to explore different gameplay options.
- **Progress tracking:** Keep track of the number of completed words.
- **Responsive interface:** The layout adapts to smaller screens to support different devices.

## Technologies

- HTML5
- CSS3 — styling, animations, and responsive layouts
- JavaScript — game logic, interactions, and dynamic content

## Getting Started

The game runs directly in a web browser and does not require any additional dependencies or installation.

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Start playing by selecting the balloons with the letters needed to complete each word.
